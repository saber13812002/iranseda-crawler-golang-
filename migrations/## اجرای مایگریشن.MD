## اجرای مایگریشن

- **پیش‌نیاز:** مطمئن شوید `.env` یا کانکشن دیتابیس (هاست، پورت، یوزر، پسورد، نام DB) آماده است و ستون‌های جدید هنوز در دیتابیس اضافه نشده‌اند.

### 1. با mysql CLI
1. روی سرور/لوکال به شاخه پروژه بروید.
2. دستور زیر را (با جایگزینی مقادیر) اجرا کنید:
   ```
   mysql -h 192.168.2.160 -u n8nuser -p radio < migrations/2025-11-19_program_legacy_columns.sql
   ```
   بعد از وارد کردن پسورد، ALTER اجرا می‌شود.

### 2. داخل محیط MySQL
1. `mysql -h ... -u ... -p` بزنید و DB را انتخاب کنید: `USE radio;`
2. محتوای فایل `migrations/2025-11-19_program_legacy_columns.sql` را کپی و در کنسول اجرا کنید.

### 3. از طریق GUI (Navicat، DBeaver و غیره)
- به دیتابیس `radio` وصل شوید، پنجره اجرای SQL را باز کنید، فایل را باز یا متن داخل آن را کپی و Run کنید.

### بعد از اجرا
- اگر جدول از قبل ستون داشته باشد، `IF NOT EXISTS` جلوی خطا را می‌گیرد.
- برای اطمینان نتیجه:
  ```
  DESC radio_programs;
  ```
  باید دو ستون `is_legacy` و `legacy_expires_at` را ببینید.
- سپس یک بار اسکریپت بک‌فیل را اجرا کنید:
  ```
  python scripts/backfill_program_times.py
  ```
  این کار مقداردهی اولیه/تشخیص تغییر را انجام می‌دهد.

اگر نیاز به اجرای چند مایگریشن داشتید، همین روش را با فایل‌های دیگر تکرار کنید (ترتیب زمانی را رعایت کنید).
