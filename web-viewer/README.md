# نمایشگر وب برنامه‌های رادیو ایران

این پروژه یک وب‌سایت برای نمایش برنامه‌های رادیو ایران و زیرنویس‌های آن‌ها است.

## ویژگی‌ها

- نمایش لیست برنامه‌های رادیو
- نمایش جزئیات هر برنامه و زیرنویس‌های آن
- جستجو در برنامه‌ها و زیرنویس‌ها
- ایجاد نسخه پشتیبان از دیتابیس به صورت JSON
- امکان کپی و دانلود زیرنویس‌ها
- رابط کاربری زیبا و واکنش‌گرا

## پیش‌نیازها

- Go 1.21 یا بالاتر
- MySQL 5.7 یا بالاتر
- دسترسی به دیتابیس رادیو ایران

## نصب و راه‌اندازی

1. کلون کردن مخزن:
```bash
git clone https://github.com/yourusername/iranseda-web-viewer.git
cd web-viewer
```

2. نصب وابستگی‌ها:
```bash
go mod download
```

3. ایجاد فایل `.env` و تنظیم اطلاعات دیتابیس:
```
DB_USER=your_username
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=3306
DB_NAME=radio
```

4. اجرای برنامه:
```bash
go run main.go
```

5. باز کردن مرورگر و رفتن به آدرس:
```
http://localhost:8080
```

## ساختار پروژه

```
web-viewer/
├── main.go           # فایل اصلی برنامه
├── templates/        # قالب‌های HTML
│   ├── index.html    # صفحه اصلی
│   └── program.html  # صفحه جزئیات برنامه
├── static/          # فایل‌های استاتیک
├── backups/         # پوشه نسخه‌های پشتیبان
├── go.mod           # فایل مدیریت وابستگی‌ها
└── .env             # فایل تنظیمات محیطی
```

## API‌ها

- `GET /api/programs`: دریافت لیست همه برنامه‌ها
- `GET /api/programs/:id`: دریافت اطلاعات یک برنامه خاص
- `POST /api/backup`: ایجاد نسخه پشتیبان از دیتابیس
