# مرحله ۴ – متن کامل و پاک‌سازی / Stage 4 – Full-Text Cleanup

## 🎯 هدف / Goal
- تبدیل زیرنویس خام به نسخه‌های تمیز و متنی که برای جست‌وجو، ویرایش و نمایش در سایت قابل استفاده باشند.

## 🧱 اجزای اصلی / Core Components
- n8n workflow `srt_clean.json`: اجرای اسکریپت `cleanall.sh` در مخزن `tools/srt_cleaner`.
- `downloads/cleaned/`: مقصد فایل‌های SRT/TXT تمیز.
- `convert_srt_to_txt.py`: اسکریپت داخلی برای تبدیل بلوک‌های SRT به متن پیوسته (`.txt`) کنار فایل اصلی.
- `generate_site.py`: تابع `find_subtitles_for_session` خروجی‌های «زیرنویس» و «متن کامل» را از این پوشه‌ها می‌خواند.

## ⚙️ معماری و جریان داده / Architecture & Flow
1. **ورودی**: فایل‌های `.srt` تولیدشده در مرحله ۳.
2. **Clean Pipeline**: n8n هر ۲ ساعت `cleanall.sh` را در مسیر `/mnt/data/saberprojects/tools/srt_cleaner/srt_cleaner` اجرا می‌کند که شامل:
   - حذف نویز، تگ‌ها و کاراکترهای اضافی
   - نرمال‌سازی فاصله‌ها و تبدیل اعداد
   - ذخیره خروجی در `downloads/cleaned/`.
3. **Text Conversion**: اسکریپت `convert_srt_to_txt.py` (قابل اجرا دستی یا از طریق Cron) همه فایل‌های `.srt` را به متن ساده `.txt` تبدیل می‌کند.
4. **آماده‌سازی برای مرحله ۶**: ساختار پوشه به شکل `downloads/<name>.srt` و `downloads/cleaned/<name>.srt|.txt` است تا سایت بتواند لینک «زیرنویس» و «متن کامل» را کنار هم نمایش دهد.

## 🔗 ارتباط با مراحل دیگر / Relationships
- ورودی از مرحله ۳؛ خروجی مستقیم برای مرحله ۶ (ساخت سایت) و هر ابزار تحلیلی دیگر.
- اگر نیاز به استخراج بخش‌های خاص برنامه باشد (فیچر آینده)، داده تمیز شده مبدا اصلی خواهد بود.

## 🛠️ تنظیمات و متغیرها / Configuration
- `srt_clean.json` دستور زیر را اجرا می‌کند:
  ```
  ./cleanall.sh
  cwd: /mnt/data/saberprojects/tools/srt_cleaner/srt_cleaner
  ```
  در صورت تغییر مسیر ابزار یا نام اسکریپت، این فایل و workflow را به‌روزرسانی کنید.
- برای اجرای محلی `convert_srt_to_txt.py`:
  ```
  python3 convert_srt_to_txt.py
  ```
  مسیر `downloads_path` در ابتدای فایل را در صورت جابه‌جایی تنظیم کنید.

## 🧪 تست و مانیتورینگ / Testing
- پس از اجرای `cleanall.sh`، یک فایل از `downloads/cleaned` را بررسی و با نسخه خام مقایسه کنید.
- برای اطمینان از عملکرد اسکریپت تبدیل، یک فایل خطادار را حذف کنید تا اسکریپت مجدداً آن را تولید کند.

## ⚠️ نکات نگهداری / Maintenance Notes
- اگر ساختار نام فایل‌ها در مرحله ۲ تغییر کند، این مرحله باید همچنان بتواند فایل هم‌نام را پیدا کند؛ در غیر این صورت منطق `stem` را به‌روزرسانی کنید.
- هنگام افزودن مرحله جدیدی (مثلاً خلاصه‌سازی)، خروجی cleaned را منبع استاندارد در نظر بگیرید و آن فرآیند را در این سند لینک دهید.

## 📝 یادداشت به‌روزرسانی / Update Memo
- هر تغییری در مسیر `downloads/cleaned`, نام اسکریپت‌ها یا فرمت خروجی باید در این فایل ثبت شود تا تیم تولید سایت و n8n از آن آگاه باشند.
