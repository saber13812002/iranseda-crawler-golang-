## پنج نکته که قبل از اجرا باید جدی گرفته شوند

1. **سه فایل 013، 014 و 015 حتماً در Commit اولیه حفظ شوند؛** اما فقط پس از بررسی محتوای آن‌ها و بدون Stage کردن کورکورانه تمام فایل‌های Untracked. (فایل 016 این سند نیز جزو مستندات مرجع است و باید در همان چک‌پوینت یا Commit مستندات بعدی ثبت شود.)

2. **عدم تکرار Commit:** ابتدا تاریخچه هر دو شاخه و محتوای فایل‌ها بررسی شود. اگر تغییر قبلا‌ وجود دارد، دوباره Commit نشود.

3. **دو مقصد Git:** تکلیف GitHub و GitLab داخلی روشن باشد. الزام دو مقصد در 014 نباید ناخواسته در اجرای 015 حذف شود؛ اگر 015 فقط GitHub را هدف می‌گیرد، این تفاوت در گزارش صریحا‌ ثبت شود.

4. **اولویت بازیابی سرویس:** تا وقتی Reporter، Cron و تولید SRT سالم نشده‌اند، توسعه قابلیت جدید اولویت ندارد.

5. **تأیید واقعی:** هر مرحله باید تست، Commit، Push، SHA و گزارش مستقل داشته باشد.
