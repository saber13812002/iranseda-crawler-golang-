# 🧹 Full Text Cleanup - پاک‌سازی و تبدیل متن

## 📋 نمای کلی

پاک‌سازی زیرنویس‌های خام و تبدیل آن‌ها به متن کامل و قابل استفاده.

## 🎯 عملکرد

این مرحله شامل دو بخش است:

### 1. پاک‌سازی زیرنویس‌ها (SRT Cleaner)

ابزار خارجی که در مسیر زیر قرار دارد:
**مسیر**: `/mnt/data/saberprojects/tools/srt_cleaner/srt_cleaner`

#### فرآیند پاک‌سازی

- حذف نویز و کاراکترهای اضافی
- نرمال‌سازی فاصله‌ها
- تبدیل اعداد فارسی/انگلیسی
- حذف تگ‌های HTML (در صورت وجود)

#### خروجی

فایل‌های پاک‌سازی شده در پوشه `downloads/cleaned/` ذخیره می‌شوند.

### 2. تبدیل SRT به TXT

اسکریپت داخلی `convert_srt_to_txt.py` که:
- فایل‌های `.srt` را می‌خواند
- تایم‌کدها و شماره‌ها را حذف می‌کند
- متن را به صورت پیوسته تبدیل می‌کند
- فایل `.txt` هم‌نام ایجاد می‌کند

## 📁 فایل‌ها

- **`convert_srt_to_txt.py`** - تبدیل SRT به TXT
- **`srt_cleaner/cleanall.sh`** - اسکریپت پاک‌سازی (ابزار خارجی)

## 🔧 تنظیمات n8n

cd /mnt/data/saberprojects/tools/srt_cleaner/srt_cleaner

## 🚀 اجرای دستی

### تبدیل SRT به TXT

```bash
python convert_srt_to_txt.py
```

این اسکریپت:
- تمام فایل‌های `.srt` در `downloads/` را پیدا می‌کند
- برای هر فایل، فایل `.txt` هم‌نام ایجاد می‌کند
- اگر فایل `.txt` قبلاً وجود داشته باشد، skip می‌کند

### تنظیمات

در ابتدای `convert_srt_to_txt.py`:
```python
downloads_path = "./downloads"
```

## 🐛 عیب‌یابی

### خطا: "File not found"
- مطمئن شوید فایل‌های `.srt` در پوشه `downloads/` وجود دارند
- مسیر `downloads_path` را بررسی کنید

### خطا: "Permission denied"
- دسترسی نوشتن به پوشه `downloads/` را بررسی کنید
- در صورت نیاز، `chmod` را اجرا کنید

### فایل‌های `.txt` ایجاد نمی‌شوند
- فرمت فایل `.srt` را بررسی کنید (ممکن است خراب باشد)
- لاگ‌های خطا را چک کنید

## 📝 یادداشت‌ها

- این مرحله **idempotent** است
- فایل‌های موجود skip می‌شوند
- فایل‌های پاک‌سازی شده در `cleaned/` برای استفاده در سایت نگه‌داری می‌شوند
